Veroxin is a compiled language with its own compiler.
The compiler reports every error and prevents compilation until all errors are resolved.
The compiler is written in Go.


Function with one argument:
[FN:test, [V: {variable_name:int=1}]]
psh:({variable_name})
[/FN:test]

Output:1
-------------------------

Function with multiple arguments:
[FN:test, [V: {test_1:flt=0.1},{test_2:string=asd}]]
psh:({test_1},{test_2})

[/FN:test]

Output:0.1asd
-------------------------

Variable types:
	string = text
	flt = non-integer number
	int = integer
	bool = true/false = TRUE/FALSE, shortened -> T/F

Indentation is not used!
Separate scopes are not used!

Global variable -> $Global [V:variable_name:int=1] # You can "bundle" multiple variables together instead of writing "$Global" before each one. To bundle them, use "{}". Example: "$Global {[V:variable_name:int=1],[V:variable_name_2:flt=3]}"
Local variable (accessible only inside the calling function) -> $Local [FN asd, [V: {variable_name:string=asd}]]. To use multiple variables: [FN asd, [V: {variable_name:string=asd},{variable_name_2:string=asd_ketto}]]



To modify a variable after it has been created:
	To change its type:
		varname[@type:int=1] -> The "@" is the edit keyword. It is followed by the type to which the variable should be changed. Warning: changing the type does not change the value. For example, if you have a variable with the `flt` type and value and change its type to `bool`, it becomes a `bool` variable with a `flt` value.
	To change only the value:
		varname[@value:int=2] -> To change a variable's value, use the "@value" keyword.
	To change both:
		varname[@type&value:flt=3.1] -> Use "&" to combine the type and value change keywords.
	To set a variable's type from another variable:
		Global variable:
			varname[@type:[var_name2]]
		Local variable:
			Use the same syntax as for a global variable, but it can access only variables in its own function.
	To set a variable's value from another variable:
		Global variable:
			varname[@value=[var_name2]]
		Local variable:
			Use the same syntax as for a global variable, but it can access only variables in its own function.

Functions can be local or global. To set their access location, add "$Local" or "$Global" before the function name.
Local functions are available only in the file where they are written and cannot be exported or accessed from other files.
Global functions can be exported and accessed from outside their owning file.

";" separates statements such as functions and variables. It allows multiple statements to be written on the same line.
"," separates items in a list.

To access code from another `.vex` file, use `$Include filename.vex`. To include multiple files, place their names inside `{}` and separate them with commas.

The compiler reports an error when a value does not match its variable type.

	Function without arguments:
[FN:test]
psh:({}) -> NULL VALUE (No text is written)
[/FN:test]

Operators:
equal (strict equality): ==
assigned from a value or variable: =
not equal: !=
less than: <
not less than: !<
greater than: >
not greater than: !>
less than or equal to: <=
greater than or equal to: >=


Call a function without arguments: function_name[]


Conditions:
[IF : variable_name == 100 [DO: random_function_name[] ]] [/IF]
[ELIF : variable_name == 101 [DO: random_function_name_2[] ]] [/ELIF]
[ELSE: [random_function_name_3[]]] [/ELSE]
#The [DO: ...] section is optional. Add it if you want an action to run after the IF statement succeeds.
#Command words:
	DO -> do/run
	PASS -> do nothing and continue with the next line.
