Vexorin: a compiled language with its own compiler.
The compiler will throws back on every error and does not let you compile until there is no error.

One-argument function:
[FN:test, [V: {variable_name:int=1}]]
psh:({text})
[/FN:test]

Output:1
-------------------------

Multiple-argument function:
[FN:test, [V: {test_1:vfloat=0.1}{test_2:string=asd}]]
psh:({test_1},{test_2})

[/FN:test]

Output:0.1asd
-------------------------

Variant types:
    string = text
    flt = non-integer number
    int = integer
    bool = true/false = TRUE/FALSE, shortened -> T/F

Indentation is not used!
Separate scopes are not used!

Global variant -> [V: variant_name: int=1]
Local variant (accessible only in the calling function; not accessible outside the calling function) -> [FN asd, [V: {variant_name:string=asd}]]. To use multiple variants -> [FN asd, [V: {variant_name:string=asd}{variant_name_2:string=asd_ketto}]]

To modify a variant after it has been created:
    To change its type:
        varname[@type:int=1] -> The "@" is the edit keyword. It is followed by the type you want to change the previous type to. WARNING! If you change a variant type but do not change its value, the following occurs:
        Any number greater than 0 becomes true. For example, if you change an int variant with value 1 to bool, it becomes TRUE.
    To change only the value:
        asd

1. Function declarations:
    Function without arguments:
[FN:test]
psh:({}) -> NULL VALUE (No text is written)
[/FN:test]

Operators:
equal (strict equality): ==
equal (to a value or variant): =
not equal: !=
less than: <
not less than: !<
greater than: >
not greater than: !>
less than or equal to: <=
greater than or equal to: >=


Call a function without arguments: function_name[]


Condition:
[IF : variant_name == 100 [DO: random_function_name[] ]] [/IF]
[ELIF : variant_name == 101 [DO: random_function_name_2[] ]] [/ELIF]
[ELSE: [random_function_name_3[]]] [/ELSE]
#The [DO:[]] section is optional. Add it if you want an action to run after the if statement executes successfully.
#Command words:
    DO -> do/run
    PASS -> do nothing and continue with the next line.
