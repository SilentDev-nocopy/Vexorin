Vexorin: a compiled language with its own compiler.
The compiler will throws back on every error and does not let you compile until there is no error.
Its own compiler will be writen in GO.


One-argument function:
[FN:test, [V: {variable_name:int=1}]]
psh:({text})
[/FN:test]

Output:1
-------------------------

Multiple-argument function:
[FN:test, [V: {test_1:flt=0.1}{test_2:string=asd}]]
psh:({test_1},{test_2})

[/FN:test]

Output:0.1asd
-------------------------

Variant types:
    string = text
    flt = non-integer number
    int = integer
    bool = true/false = TRUE/FALSE, shortened -> T/F

Indentation is not used!
Separate scopes are not used!

Global variant -> [V: variant_name: int=1]
Local variant (accessible only in the calling function; not accessible outside the calling function) -> [FN asd, [V: {variant_name:string=asd}]]. To use multiple variants -> [FN asd, [V: {variant_name:string=asd}{variant_name_2:string=asd_ketto}]]

To modify a variant after it has been created:
    To change its type:
        varname[@type:int=1] -> The "@" is the edit keyword. It is followed by the type you want to change the previous type to. Warning! if you change the type, the value does not change! So if you have a flt type variable and value and you set its type to bool, then it will become a bool type variable with an flt value. 
    To change only the value:
        varname[@value:int=2] -> Yes. To change any variable's value, you have to use the "@value" keyword
		To change both:
				varname[@type&value:flt=3.1] -> Use the "&" to connect the type and value change keyword.
		To set a variable type to another variable's type:
				Global variable:
					varname[@type:[var_name2]]
				Local variable:
					same as global variable but it only can access it own function's variable
		To set a variable value to another variable's value:
				Global variable:
					varname[@value=[var_name2]]
				Local variable:
					varname[@value=[var_name2]]

Operators:
equal (strict equality): ==
equal (to a value or variant): =
not equal: !=
less than: <
not less than: !<
greater than: >
not greater than: !>
less than or equal to: <=
greater than or equal to: >=
